# FastAPI User API

A beginner-friendly REST API built with **FastAPI** that demonstrates basic CRUD operations for managing users.

## 🚀 Features

- Create a user
- Get all users
- Get a user by ID
- Update a user
- Delete a user
- UUID-based user IDs
- Input validation using Pydantic
- Interactive API documentation with Swagger UI
- Simple HTML/CSS/JavaScript frontend

## 🛠️ Tech Stack

- Python
- FastAPI
- Uvicorn
- Pydantic
- HTML
- CSS
- JavaScript
